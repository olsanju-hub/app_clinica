# MFyU · Esqueleto de producto (V1)

Esta versión del repositorio contiene un **prototipo estructural** (sin lógica clínica completa) para validar la arquitectura de pantallas de MFyU.

## Pantallas incluidas en esta iteración

1. Home
2. Listado de categoría (Protocolos)
3. Módulo clínico (FA)
4. Drawer clínico
5. Pantalla de herramienta
6. Pantalla de resumen final

## Objetivo

Validar jerarquía visual, navegación y flujo principal:

Home → categoría/listado → módulo → drawer/herramienta → resumen.

## Estado

- Enfoque mobile-first.
- Diseño ligero para lectura rápida en guardia.
- Contenido de ejemplo para demostrar estructura de producto.

## Nota

Este entregable es un **esqueleto UX/UI**. No sustituye protocolos locales ni juicio clínico.
